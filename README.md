# 할 일 관리 앱 (Todo App)

순수 HTML/CSS/JavaScript로 만든 개인용 할 일 관리 웹 앱입니다. 프레임워크, 라이브러리, 빌드 도구, 서버가 없습니다.

## 실행

`index.html`을 브라우저에서 열면 바로 동작합니다.

## 기능

- 할 일 추가 / 수정(더블클릭 또는 수정 버튼) / 삭제 / 완료 체크
- 업무·개인·공부 카테고리와 필터 탭
- 전체 및 카테고리별 진행률
- `localStorage`에 저장되어 새로고침 후에도 유지 (데이터는 브라우저 안에만 저장되고 외부로 전송되지 않습니다)

기획 문서는 [PRD.md](PRD.md)를 참고하세요.
