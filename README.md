# 할 일 관리 앱 (Todo App)

순수 HTML/CSS/JavaScript로 만든 개인용 할 일 관리 웹 앱입니다. 프레임워크, 라이브러리, 빌드 도구, 서버가 없습니다.

## 실행

- `index.html` — 기본(모바일 우선, 한 장짜리 카드) 화면
- `web_version/index.html` — 데스크톱 전체 화면용(사이드바 + 목록) 화면

브라우저에서 파일을 열면 바로 동작합니다. 두 화면은 같은 JavaScript를 쓰고 같은 브라우저 저장소를 공유합니다.

## 기능

- 할 일 추가 / 수정(더블클릭 또는 수정 버튼) / 삭제 / 완료 체크
- **날짜별 목록**: 날짜를 넘겨 지난 기록을 보고, 지난 날의 미완료 항목을 오늘로 가져오기
- **카테고리**: 기본(업무·개인·공부) + 직접 만든 카테고리(이름 변경, 색상 선택, 삭제), 필터 탭
- 입력한 단어로 카테고리 자동 선택
- 전체 및 카테고리별 진행률
- **순서 변경**: 끌어서 이동, 또는 ⋮⋮ 손잡이에서 위/아래 화살표 키 (같은 완료 상태 안에서)
- **다크 모드**: OS 설정을 따르고, 버튼으로 직접 전환 가능
- **백업**: JSON으로 내보내기 / 가져오기
- **키보드**: `/` 키로 어디서든 입력창으로 이동 (데스크톱 화면은 열자마자 입력창에 포커스, 목록을 스크롤해도 입력창이 위에 고정)
- 모든 데이터는 브라우저의 `localStorage`에만 저장되고 외부로 전송되지 않습니다.
